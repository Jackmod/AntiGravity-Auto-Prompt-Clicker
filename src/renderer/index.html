About

Auto Picker

Open-source screen watcher that auto-confirms Claude Code approval prompts in the Antigravity IDE — and pauses the instant it sees anything it doesn't recognize.

  • Reads your screen locally with on-device OCR. Nothing is uploaded.
  • Only clicks when a trusted prompt phrase is present.
  • Pauses on anything ambiguous, so it never clicks the wrong thing.
  • MIT licensed · Windows & macOS.
